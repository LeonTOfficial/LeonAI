Quick start:

1. Install Ollama:
   https://ollama.com/

2. Pull the recommended models:
   ollama pull llama3
   ollama pull llama3.2:1b

3. Clone the repository:
   git clone https://github.com/LeonTOfficial/LeonAI.git
   cd LeonAI

4. Create local settings:
   cp .env.example .env

5. Start on macOS:
   chmod +x Starten.command
   ./Starten.command

6. Start on Windows or Linux:
   python -m venv venv
   pip install -r requirements.txt
   python app.py

7. Open:
   http://127.0.0.1:5001

Important:
- Ollama must be running.
- Keep `.env`, `data/`, `backup/`, databases, logs, and virtual environments out of Git.
- For errors, check `data/logs/leon.log`.
- For public release notes, update `CHANGELOG.md`.
- For detailed internal implementation notes, update `UPDATES.md`.
