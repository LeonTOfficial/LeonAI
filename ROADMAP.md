# LEON AI Roadmap

This roadmap keeps public feedback focused without turning the README into a long planning document.

## Done

- Local Flask + SQLite AI workspace with Ollama integration.
- First setup flow with local password and first name.
- Chat rooms with auto titles, favorites, pinned chats, and branching support.
- Live Artifacts preview for HTML, CSS, JavaScript, Tailwind-style layouts, and browser-side Python snippets.
- Mermaid diagrams, Chart.js charts, and safe color tags in chat messages.
- Dashboard for activity, tokens, logs, health, backups, and privacy tools.
- Backup creation, verification, and restore safety flow.
- English-first public documentation with screenshots and release notes.
- Troubleshooting guide for setup, launchers, Ollama, preview issues, logs, request IDs, and CI failures.
- Beginner setup and feedback guides for public testers.
- Privacy-safe dashboard diagnostics for support reports.
- GitHub Actions for Python tests, JavaScript syntax checks, release doctor, and browser QA.
- Dependabot dependency checks for Python, JavaScript, and GitHub Actions.

## Next

- Improve installer comfort on every platform based on real user feedback and recurring troubleshooting patterns.
- Add more browser-level regression tests for artifact preview and rich chat rendering.
- Continue polishing dashboard explanations for non-technical users.
- Turn recurring feedback into smaller v1.0.x usability fixes.
- Improve fallback behavior when optional browser libraries cannot be loaded.
- Maintain the German documentation inside `docs/de/` and keep it aligned with the English public docs.

## Later

- More accessibility checks for keyboard navigation and screen-reader labels.
- Optional packaged desktop builds after the local web app workflow is mature.
- More database migration tests for older local installs.
- Better model management UI for installed Ollama models.
- More export/import formats for conversations and artifacts.

## Feedback Wanted

Feedback is especially helpful in these areas:

- Is the README clear for a first-time user?
- Does installation feel easy on macOS, Windows, and Linux?
- Do the screenshots explain the value of the project quickly?
- Is the license summary understandable?
- Which workflows should be smoother before the next release?

Please use GitHub Issues for bugs, feature ideas, and general feedback.
