# Feedback Guide

Thank you for testing LEON AI. Honest feedback is the most useful thing for the next release.

German version: [`docs/de/FEEDBACK.md`](docs/de/FEEDBACK.md)

## What Feedback Helps Most?

| Area | Useful questions |
| --- | --- |
| Installation | Was the setup understandable on your operating system? |
| README | Did the screenshots and installation steps make sense? |
| UI/UX | Which screens felt polished, confusing, too empty, or too dense? |
| Local AI behavior | Did Ollama/model setup work as expected? |
| Artifacts | Did preview, charts, Mermaid, Pyodide, and code output behave clearly? |
| Security/privacy | Is the local-first model understandable and credible? |
| Code structure | Are routes, services, utils, tests, and docs easy to navigate? |
| License | Is the source-available license wording clear? |

## Good Feedback Format

```text
OS:
Python version:
Browser:
Ollama model:
LEON AI version or commit:

What I tried:
What worked:
What was confusing:
What I would improve:
Screenshot or error message, if safe:
```

## Safe Diagnostics

In the dashboard, use **Diagnose kopieren** to copy a privacy-safe diagnostic summary. It excludes prompts, chat content, API keys, `.env`, full logs, databases, backups, and local file paths.

## Where To Send Feedback

- Bugs: [Bug Report](https://github.com/LeonTOfficial/LeonAI/issues/new/choose)
- Feature ideas: [Feature Request](https://github.com/LeonTOfficial/LeonAI/issues/new/choose)
- General review: [General Feedback](https://github.com/LeonTOfficial/LeonAI/issues/new/choose)

Security-sensitive findings should follow [`SECURITY.md`](SECURITY.md).
