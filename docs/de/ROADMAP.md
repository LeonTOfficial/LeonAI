# LEON AI Roadmap

Diese Roadmap ist die deutsche Übersicht darüber, was bei LEON AI bereits steht, was als Nächstes sinnvoll ist und wo Feedback besonders hilfreich wäre.

Die englische Hauptdokumentation liegt im Repository-Root: [`README.md`](../../README.md).

## Erledigt

- Lokaler Flask- und SQLite-KI-Arbeitsbereich mit Ollama-Anbindung.
- First Setup mit lokalem Passwort und Vornamen.
- Chat-Räume mit Auto-Titeln, Favoriten, angepinnten Chats und Branching.
- Live Artifacts für HTML, CSS, JavaScript, Tailwind-artige Layouts und Python-Snippets.
- Mermaid-Diagramme, Chart.js-Charts und sichere Farbtags im Chat.
- Dashboard für Aktivität, Tokens, Logs, Health, Backups und Privacy.
- Backup-Erstellung, Prüfung und geschützter Restore-Flow.
- Englische Hauptdokumentation und deutscher Doku-Bereich unter `docs/de/`.
- Fehlerhilfe für Setup, Starter, Ollama, Vorschau, Logs, Request IDs und CI-Fehler.
- GitHub Actions für Python-Tests, JavaScript-Prüfung, Release Doctor und Browser-QA.

## Als Nächstes

- Installation auf macOS, Windows und Linux anhand echtem Nutzerfeedback und wiederkehrenden Fehlerbildern weiter vereinfachen.
- Browser-QA für Artifacts und Rich Rendering ausbauen.
- Dashboard-Erklärungen für normale Nutzer weiter verbessern.
- Fallbacks verbessern, wenn optionale Browser-Bibliotheken nicht geladen werden können.
- Deutsche Doku in `docs/de/` weiter an die englische Hauptdokumentation angleichen.

## Später

- Mehr Accessibility-Checks für Tastaturbedienung und Screenreader.
- Optional gepackte Desktop-Version, sobald der lokale Web-App-Workflow stabil genug ist.
- Mehr Migrationstests für ältere lokale Installationen.
- Besseres UI für installierte Ollama-Modelle.
- Weitere Export- und Importformate für Chats und Artifacts.

## Feedback erwünscht

Feedback ist besonders hilfreich zu diesen Fragen:

- Ist die README für neue Nutzer verständlich?
- Funktioniert die Installation auf macOS, Windows und Linux gut genug?
- Erklären die Screenshots schnell, worum es geht?
- Ist die Lizenz verständlich formuliert?
- Welche Workflows sollten vor der nächsten Version glatter werden?

Bitte Feedback im Hauptrepo geben: [GitHub Issues](https://github.com/LeonTOfficial/LeonAI/issues).
