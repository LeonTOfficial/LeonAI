# Feedback-Leitfaden

Danke, dass du LEON AI testest. Ehrliches Feedback ist das Wertvollste für das nächste Release.

Englische Hauptversion: [`../../FEEDBACK.md`](../../FEEDBACK.md)

## Welches Feedback hilft am meisten?

| Bereich | Gute Fragen |
| --- | --- |
| Installation | War das Setup auf deinem Betriebssystem verständlich? |
| README | Waren Screenshots und Installationsschritte klar? |
| UI/UX | Welche Screens wirkten sauber, verwirrend, zu leer oder zu voll? |
| Lokale KI | Hat die Einrichtung mit Ollama und Modellen funktioniert? |
| Artifacts | Waren Vorschau, Charts, Mermaid, Pyodide und Code-Ausgaben nachvollziehbar? |
| Sicherheit/Privatsphäre | Ist das Local-First-Modell verständlich und glaubwürdig? |
| Code-Struktur | Sind Routes, Services, Utils, Tests und Doku leicht zu verstehen? |
| Lizenz | Ist die Source-Available-Lizenz klar formuliert? |

## Gutes Feedback-Format

```text
Betriebssystem:
Python-Version:
Browser:
Ollama-Modell:
LEON-AI-Version oder Commit:

Was ich getestet habe:
Was funktioniert hat:
Was verwirrend war:
Was ich verbessern würde:
Screenshot oder Fehlermeldung, falls sicher:
```

## Sichere Diagnose

Im Dashboard kannst du **Diagnose kopieren** nutzen. Dadurch wird eine datensparsame Diagnose kopiert. Sie enthält keine Prompts, Chat-Inhalte, API-Schlüssel, `.env`, vollständige Logs, Datenbanken, Backups oder lokalen Dateipfade.

## Wohin mit Feedback?

- Bugs: [Bug Report](https://github.com/LeonTOfficial/LeonAI/issues/new/choose)
- Ideen: [Feature Request](https://github.com/LeonTOfficial/LeonAI/issues/new/choose)
- Allgemeine Einschätzung: [General Feedback](https://github.com/LeonTOfficial/LeonAI/issues/new/choose)

Sicherheitsrelevante Funde bitte nach [`SECURITY.md`](SECURITY.md) behandeln.
